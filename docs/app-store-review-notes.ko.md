# App Store 심사용 앱 설명서 (eerme)

## 1) 앱 개요
**eerme**는 사용자가 하루를 **세 줄 문장(3-line journal)**으로 기록하고, 일정·검색·통계·동기화 기능으로 회고를 이어갈 수 있도록 돕는 개인 저널 앱입니다.

- 플랫폼: iOS / Android (Expo 기반)
- 핵심 사용 시나리오:
  1. 오늘의 감정/사건을 3줄로 입력
  2. 날짜별 기록 확인(캘린더)
  3. 키워드 검색으로 과거 기록 탐색
  4. 월간 통계 및 연속 기록 확인
  5. 계정 로그인 후 원격 동기화 및 백업/복원

---

## 2) 심사자가 확인할 핵심 기능

### A. 오늘 탭 (기록 작성)
- 하루 기록을 3줄 텍스트로 입력/저장/삭제할 수 있습니다.
- 입력값은 공백 방지 및 글자수 제한 검증이 적용됩니다.
- 최근 기록을 빠르게 확인할 수 있습니다.

### B. 캘린더 탭
- 날짜별로 기록이 존재하는지 확인할 수 있습니다.
- 특정 날짜를 선택해 해당 일자의 기록을 조회/편집할 수 있습니다.

### C. 검색 탭
- 저장된 저널 문장을 키워드로 검색해 필터링합니다.

### D. 통계 탭
- 월간 기록일/문장 수, 연속 기록(streak), 상위 키워드 등 개인 회고 지표를 제공합니다.

### E. 동기화 탭
- 이메일/소셜 로그인 후 클라우드 동기화를 수행합니다.
- 네트워크 실패 시 로컬 큐에 보관 후 재시도하여 데이터 손실 가능성을 낮춥니다.
- 최신 수정 시간 기준(LWW)으로 충돌을 처리합니다.

### F. 백업/복원
- JSON 내보내기/가져오기 방식으로 데이터 백업/복원을 지원합니다.
- 파일 공유 시트를 통한 파일 내보내기가 가능합니다.

---

## 3) 유료 기능(In-App Purchase) 안내
- 앱에는 프리미엄 구독(월 구독) 상품이 포함되어 있습니다.
- 프리미엄 상태에서는 일부 고급 기능(예: 첨부/백업/확장 기능 등)이 활성화됩니다.
- 구매 복원 기능을 제공하여 기존 구매자가 상태를 복구할 수 있습니다.

> 심사 환경에서 실제 결제는 샌드박스 계정을 사용해 검증 가능합니다.

---

## 4) 계정/로그인 관련 안내
앱은 동기화를 위해 로그인 기능을 제공합니다.

- 이메일 로그인
- Apple 로그인
- Google 로그인

로그인 없이도 일부 로컬 기능은 사용할 수 있으나, **다중 기기 동기화/클라우드 저장**은 로그인 후 사용됩니다.

---

## 5) 권한 사용 목적
앱에서 요청 가능한 주요 권한의 목적은 아래와 같습니다.

- **사진/파일 접근 권한**: 기록 첨부 또는 백업 파일 가져오기/내보내기
- **네트워크 접근**: 사용자 계정 인증 및 원격 동기화

수집 데이터는 저널 기능 제공(저장/동기화/복원)을 위한 목적 범위에서만 사용됩니다.

---

## 6) 심사 시 권장 테스트 플로우
1. 앱 실행 후 오늘 탭에서 3줄 기록 작성 및 저장
2. 캘린더/검색에서 방금 저장한 데이터 조회
3. 통계 탭에서 지표 반영 여부 확인
4. 동기화 탭에서 로그인 후 동기화 실행
5. (선택) 프리미엄 구매/복원 플로우 확인
6. (선택) 백업 내보내기 후 가져오기로 복원 확인

---

## 7) 심사 참고 메모
- 본 앱은 사용자 개인 저널/회고 생산성 앱으로, UGC 공개 피드나 커뮤니티 기능은 포함하지 않습니다.
- 의료/금융/법률 판단을 제공하지 않으며, 개인 기록 관리 도구에 해당합니다.
- 광고 SDK 기반 추적 중심 앱이 아니라 기록/동기화 중심의 유틸리티 앱입니다.

필요 시 위 문구를 App Store Connect의 **App Review Information > Notes**에 그대로 붙여넣어 제출하셔도 됩니다.
